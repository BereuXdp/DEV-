# Suporte Dev+

Páginas de suporte da Dev+ (devmais.com): abrir chamado (`suporte.html`) e consultar a ordem de serviço (`suporte-consulta.html`).

Protótipo: os chamados ficam só no navegador de quem usa. A fonte fica no projeto do Opiina (`painel/suporte*`); esta pasta é gerada por `tools/atualizar-suporte-devmais.ps1`.
